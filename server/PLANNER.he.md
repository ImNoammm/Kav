# מתכנן מסלולים משלכם

השרת של Kav מתכנן נסיעות עם OpenTripPlanner, שנבנה כל לילה מלוח הזמנים של המשרד ומ-OpenStreetMap
([server/selfhost](selfhost/README.md)). אפשר לשים במקומו כל מתכנן אחר, באחת משתי הדרכים שבהמשך. בדף ההגדרה:
Parts › Trip planner › My own planner. ידנית: ב-`.env`, עם `PLANNER=own`, כדי שהבנייה הלילית לא תבנה מתכנן שלא
תשתמשו בו.

## OpenTripPlanner משלכם {#your-own-opentripplanner}

```
OTP_URL=http://my-otp:8080/otp/gtfs/v1
```

OpenTripPlanner שאתם מריצים, או כל דבר אחר שעונה ל-GTFS GraphQL API שלו באותה צורה (`planConnection`). Kav
מריצה את גרסה 2.10, ושואלת אותו את מה שהיא שואלת את המתכנן שלה. השרת של Kav עדיין בוחר את המסלולים, מסדר אותם ומוסיף
את השאר (הקווים האחרים מאותה תחנה, כרטיס המוניות וכו'), אז האפליקציה נראית אותו דבר.

השרת מחשיב את המתכנן כפעיל כש-`{ serviceTimeRange { end } }` מחזיר לוח זמנים שעוד לא נגמר.

## מתכנן שכתבתם {#a-planner-you-wrote}

```
PLAN_URL=http://my-planner:9000/plan
```

בכל שפה ובכל שיטה. כל נסיעה שהאפליקציה מבקשת מגיעה אליו כך:

```
GET <PLAN_URL>?from=<lat>,<lon>&to=<lat>,<lon>&time=<unix seconds>&way=<d|a|n|l>[&modes=0,3][&via=<lat>,<lon>;<lat>,<lon>]
```

- `way`: `d` לצאת בשעה הזאת, `a` להגיע עד השעה הזאת, `n` לצאת עכשיו, `l` הדרך האחרונה להגיע באותו לילה.
- `modes`: סוגי הקווים ב-GTFS שהנוסע מרשה (`0` רכבת קלה, `2` רכבת, `3` אוטובוס, ...). בלי הפרמטר, כולם.
- `via`: עד שלושה מקומות לעבור בהם בדרך. הדקות שהנוסע ביקש לעצור במקום לא עוברות למתכנן.

המתכנן עונה עם המסלולים, בפורמט שהאפליקציה קוראת: [תכנון מסלולים ב-server/API.md](API.md#plan). `it` חובה. אם
`stops`, `lines`, `agencies` ו-`errors` חסרים, הם מתמלאים כריקים. השרת של Kav מעביר את התשובה כמו שהיא, אז הסדר,
התגיות והחלקים במסך בידיים שלכם.

אם `GET <PLAN_URL>` פשוט עונה בקוד מתחת ל-400, האפליקציה יודעת שהמתכנן פעיל. השרת מחכה לתשובה 30 שניות.

מזהי הקווים וקודי התחנות הם של המשרד (`route_id` ו-`stop_code` של GTFS), כדי שהאפליקציה תוכל להתאים את הנסיעות
שלכם לאוטובוסים בזמן אמת וללוחות התחנות.

## להתחיל מהדוגמה {#start-from-the-example}

`server/examples/planner.py` הוא המתכנן הכי קטן שיש: הוא עונה עם מסלול אחד, הליכה ישר ליעד.

```sh
python3 server/examples/planner.py                                 # serves on :9000
python3 server/conformance.py plan http://127.0.0.1:9000/plan      # checks it
```

## לבדוק את המתכנן שלכם {#checking-yours}

```sh
python3 server/conformance.py plan http://my-planner:9000/plan
```

הסקריפט מבקש נסיעה ממרכז תל אביב לאוניברסיטת תל אביב, עם יציאה בעוד עשר דקות, ומפרט כל מה שהאפליקציה לא הייתה
מצליחה לקרוא בתשובה: שדות חסרים, זמנים שהם לא שניות unix, נסיעות שהקו או התחנות שלהן לא מופיעים ב-`lines`
וב-`stops`. כשהכול תקין, קוד היציאה הוא 0.
