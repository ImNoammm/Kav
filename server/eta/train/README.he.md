# לאמן מודל

החיזוי של Kav (`server/eta/eta.py`) מריץ כל מודל שמגיע כחבילת מודל ([server/PREDICTOR.md](../../PREDICTOR.md)).
הסקריפטים כאן בונים חבילה כזאת מההיסטוריה של השרת שלכם: מתי כל אוטובוס עבר בכל תחנה, מה שהשרת שומר עשרה שבועות
ב-`data/history`. הרשת זהה לזו של המודל של Kav ומאומנת באותה דרך, וכל קלט שהיא לומדת ממנו נוצר בקוד של
החיזוי עצמו, אז היא רואה בדיוק את מה שהחיזוי ייתן לה.

הסקריפטים מייצרים מודלים מסוג `live3`: אוטובוסים, מהמעברים ומלוח הזמנים. ה-`live5` של Kav צריך גם לדעת איפה כל
אוטובוס היה בכל דקה, ושרת לא שומר את זה, אז אי אפשר לאמן אותו מההיסטוריה של שרת.

## מה צריך {#what-it-takes}

- לפחות ארבעה שבועות של היסטוריה, וכמה שיותר יותר טוב, עד עשרת השבועות ששרת שומר. השבועיים הראשונים משמשים רק
  לחישוב החציונים (כמה זמן לוקח בדרך כלל לעבור כל קטע), והימים שאחריהם הם הדוגמאות.
- מחשב עם 8 GB זיכרון ו-Python 3.12. לא צריך כרטיס גרפי.
- בערך 150 MB של הורדות לכל שבוע של היסטוריה: לוח הזמנים של המשרד לכל שבוע, מהארכיון הפתוח של הסדנא לידע ציבורי.

## צעד אחרי צעד {#step-by-step}

1. **ההיסטוריה.** בדף ההגדרה, ב-Storage, מורידים את המעברים ופורסים אותם: `tar xf kav-history.tar` יוצר תיקייה
   בשם `history`. כדי לאמן על השרת עצמו, משתמשים בשלב 3 בתיקיות שלו:
   `--history ~/kav-server/data/history ~/kav-server/data/history-backfill` (בשנייה יש מעברים ישנים יותר שנוספו
   ידנית, אם יש). הן שייכות למשתמש 1000, אז מריצים את הסקריפטים בתור המשתמש הזה או בתור root.

2. **להתקין**, פעם אחת:

   ```sh
   python3 -m venv ~/kav-train
   ~/kav-train/bin/pip install polars==2.0.0 numpy==2.5.4
   ~/kav-train/bin/pip install torch --index-url https://download.pytorch.org/whl/cpu
   ```

   Polars ו-numpy באותן גרסאות שהחיזוי משתמש בהן, כדי שהקלטים ייצאו אותו דבר.

3. **הדוגמאות**, מתוך clone של הריפו (`git clone https://github.com/ImNoammm/kav`, כי בתיקייה של השרת עצמו אין קוד,
   רק האימג'ים שלו):

   ```sh
   ~/kav-train/bin/python server/eta/train/examples.py --history history --work ~/kav-model
   ```

   בערך דקה ו-5 GB זיכרון לכל יום. אפשר לעצור מתי שרוצים: מריצים שוב, והוא ממשיך מאיפה שעצר.

4. **לאמן:**

   ```sh
   ~/kav-train/bin/python server/eta/train/train.py --work ~/kav-model
   ```

   3 הימים האחרונים נשמרים בצד בשביל הציון, ו-2 הימים שלפניהם מראים איך הוא מתקדם אחרי כל סבב. הסקריפט כותב את
   `~/kav-model/live3.npz` ובודק שה-`Model` של eta.py נותן את אותם זמנים כמו הרשת שהוא אימן. זה לוקח דקות: על
   הדוגמאות של 8 ימים זה לקח דקה אחת, על 4 threads של המעבד. אם מריצים שוב על אותו מחשב עם אותו `--seed`, יוצא
   אותו מודל בדיוק.

5. **ציון:**

   ```sh
   ~/kav-train/bin/python server/eta/train/score.py --work ~/kav-model
   ```

   ```
   Held out: 2026-11-04, 2026-11-05, 2026-11-06, 345386 questions.
   Buses that came within 2 minutes of the time given, by how long until they came:

                      0-10 min  10-20 min  20-40 min  40-60 min        all   median error
   your model            93.5%      66.0%      46.7%      31.6%      80.1%           45 s
   keep the delay        82.0%      30.3%      13.9%       4.7%      61.2%           78 s
   the timetable         48.2%      15.6%       9.4%       3.7%      35.8%          198 s
   ```

   זה מודל שאומן על 8 ימים מהשרת של Kav עצמו (25 באוקטובר עד 1 בנובמבר 2026, `--warmup 7`). בטבלה: אחוז
   האוטובוסים שהגיעו בטווח של 2 דקות מהזמן שנחזה, לפי הזמן שנותר עד ההגעה.

   השורה "keep the delay" מניחה שכל אוטובוס יישאר באותו איחור שהיה לו בתחנה האחרונה. אם המודל שלכם לא עוקף אותה, אל
   תשתמשו בו: אמנו על יותר ימים.

6. **לארוז:**

   ```sh
   ~/kav-train/bin/python server/eta/train/pack.py --work ~/kav-model --name my-model
   ```

   הסקריפט כותב את `~/kav-model/my-model-<date>.tar.gz` ומדפיס את ה-sha256 שלו, אחרי שהוא קורא אותו בחזרה כמו
   שהשרת יקרא אותו.

7. **להשתמש.** שמים את ה-`.tar.gz` במקום שאפשר להוריד ממנו ב-HTTPS (למשל release ב-fork שלכם). בדף ההגדרה:
   Parts › Arrival times › **Kav's predictor with my own model**, ונותנים את הכתובת. הבנייה הלילית מורידה את
   החבילה, ומאז החיזוי מריץ אותה. הדשבורד מציג את השם והגרסה שלה.

## רכבות ורכבת קלה {#trains-and-light-rail}

הסקריפטים האלה מאמנים רק את המודל לאוטובוסים. כדי להשאיר את המודלים של Kav לרכבת ולרכבת הקלה, שמים אותם בחבילה
שלכם: פורסים את `kav-eta-models.tar.gz` מה-release `eta-models-2026-10-27` ב-GitHub, ומוסיפים בשלב 6
`--rail <its rail folder>` (התיקייה `rail` שבתוכו).

## הגדרות {#settings}

| סקריפט | הגדרה | ברירת מחדל |
|---|---|---|
| `examples.py` | `--warmup`: כמה ימי היסטוריה משמשים רק לחישוב החציונים | 14 |
| | `--moments`: כמה נקודות זמן ביום שואלים עליהן (בכל אחת שואלים על עד 10 תחנות קדימה) | 20000 |
| `train.py` | `--sample`: מקסימום דוגמאות אימון | 3000000 |
| | `--epochs`, ואחריו `--window`: סבבים, ואחריהם סבבים שמכוונים ישר למדד של 2 הדקות | 3, 1 |
| | `--test-days`, `--valid-days`: הימים האחרונים שנשמרים בצד | 3, 2 |
| | `--seed`, `--threads` | 0, כולם |
| `pack.py` | `--version`, מוצג ליד השם | היום |

חגים לא נכנסים לדוגמאות, כמו שהמודל של Kav לא כלל אותם, וגם לא יום עם הרבה פחות מעברים מהרגיל לאותו יום בשבוע
(שביתה, או שהשרת לא עבד).
